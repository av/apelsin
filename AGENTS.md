The realism bar is `/tmp/apelsin-work/refs/ivan-reference-wedges.jpg` (when present), and the numbers come from `/tmp/apelsin-work/research/REALISM.md`.

## Scope

One navel orange on one white studio cove. Interactions: knife, hand, orbit/zoom, presets Whole / Halves / Wedges / Reference, New orange, Screenshot, Sound. Varieties, the kitchen and dark scenes, squeeze, slow motion, the macro toggle and the Wheels preset were removed on purpose; do not bring them back.

## Conventions

- Buildless ES modules served as static files. No bundler, no TypeScript, no runtime CDN. The only runtime dependency is `vendor/rapier/rapier.mjs`.
- No code comments of any kind. Shaders live in JS modules as template strings.
- Tests are end-to-end only (`test/e2e.test.mjs`: node --test + playwright-core + system Chrome). Every behaviour change gets a user-visible assertion there. Look at your own screenshots.
- Units: metres, Y up, floor top at y = 0. Author colours in linear space; sRGB happens only in the tonemap pass.
- **Rest-space rule**: piece vertices stay in the orange's rest space forever (origin = orange centre, +Y = stem). The model matrix is `T(position) · R(rotation) · T(−com)`, where `position` is the body's world centre of mass (`orange/piece.js updateModel`). Shading is a function of rest position.
- Commit each logical change. Messages are lowercase and imperative, under 72 chars.

## Contracts

- **Shape** (`src/orange/shape.js`, the single source of truth for where surfaces are): `createShape(seed, params)` (use `shapeOf(params)` from `mesh.js`, memoised per params object) returns `{ radius(d), envelope(d), relief(d), pulpRadius(d), flavedo(d), peel(d), sample(d) → [outerR, pulpR, flavedoR, peel], glandAt(d), glands, glandShape, glandCount, base, axis, calyx, navelOpen, bake(gl), dispose(gl) }`. `d` is a unit rest-space direction, +Y = stem, −Y = navel; values are metres. `flavedo(d)`/`peel(d)` are thicknesses; `flavedoR = outerR − flavedo`. `envelope(d) = radius(d) + relief(d)` is the true outer surface (relief = calyx crown and stem stub, zero outside ~6 mm of the stem pole). `base` is the rest direction of the flattened resting spot. Statistics: ≈1.4–1.9 % RMS radial deviation (SH l=2..8), flat base, shoulders, stem dip, navel hole; every seed differs.
  - `glands`: `Float32Array`, `GLAND_STRIDE = 5` per gland: x, y, z (point on the outer surface above the gland), tangential radius, depth of the gland centre below the surface. ≈9.4k glands, mean nearest-neighbour 1.1 mm. The rind pits are baked at exactly these points.
  - `bake(gl)` (memoised per context) → `{ shape, glands, relief, uniforms: { uShape, uGlands, uRelief }, cube, texture, size }`. Bind every entry of `uniforms` by name. `uShape`: RGBA16F 128² cube (outerR, pulpR, flavedoR, 0, stored minus `SHAPE_BIAS`). `uGlands`: RGBA32F 512² cube, NEAREST: per direction the nearest gland's **centre** (rest metres, below the surface) and tangential radius (0 = no gland within 1.6 mm, e.g. on the calyx). `uRelief`: R16F 256² gnomonic map around +Y (relief in mm).
  - GLSL `SHAPE_GLSL` (needs those three samplers): `vec4 shapeAt(vec3 restDir)` → (outerR, pulpR, flavedoR, 0); `vec4 glandAt(vec3 restDir)` → (gland centre xyz, radius); the gland cavity is an ellipsoid with tangential semi-axis `w` and radial semi-axis `GLAND_RADIAL · w` (1.25), always inside the flavedo; `float envelopeRelief(vec3 p)` → metres to add to `shapeAt(d).x` (the envelope SDF is `length(p) − (shapeAt(d).x + envelopeRelief(p))`; the stub wall is steep, so step ≤ 0.3× the distance within ~3 mm of the stem pole).
- **Rind** (`src/orange/rind.js`, `rind-glsl.js`): `orangeTextures(gl, params)` bakes (≈0.2 s per orange incl. shape) and returns the sampler map `{ uShape, uGlands, uRelief, uRindN, uRindC }`; `main.js` passes it to `renderer.setOrange(packed, textures)`, which binds it on every material program. `uRindN`/`uRindC` are 1024² mipmapped RGBA8/SRGB8_ALPHA8 cubes: rest-space slope gradient (±`RIND_GMAX`) + LEAN second moment, and albedo + base roughness. Content: gland pits (summed per-gland cushion + core kernels, no Voronoi creases), lemon-scan micro relief hex-tiled triplanar, 2–6 mm undulation, colour only ≥ 10 mm plus per-gland specks, scars, smudge, calyx/stub/folds, navel puckers. `Surface rindSurface(SurfaceInput si)` is a pure function of `si.rest`, `si.restNormal` (macro normal of the envelope), `si.V`, `si.restToWorld`, `si.pixel` (world footprint of a pixel) and those textures; explicit `textureGrad`, so it is safe inside march loops and branches. It needs `NOISE`, `SURFACE`, `SHAPE_GLSL` before it. Two lobes: base f0 0.015 broad + wax coat (F0 0.04, α ≈ 0.1–0.22), Toksvig/LEAN widening from the mips.
- **Environment**: `scenes.studio.env.hdri = { url, scale, yaw, clamp }` replaces the procedural gradient with `assets/hdri/monochrome_studio_03_1k.hdr` for ambient and reflections (radiance clamped to 3 so wet flat faces do not blow out); the key light (light 0, key cube, shadows) is unchanged. `renderer.ibl.ready()` resolves once the HDRI is baked; `ready` waits for it and for the rind atlas.
- **Assets**: CC0 only, listed in `assets/SOURCES.md`.

- **Uniform blocks**: `Frame` (binding 0, `src/shaders/common.js`; packed in `renderer.js fillFrame` with the offsets in `F`), `Orange` (binding 1, `src/orange/glsl.js`; packed by `packOrange`). If you add a field, update the GLSL block, the float count and the packer together.
  - `Orange` tail (orange): Orange ends with `oFleshDeep` (flesh colour next to the dorsal wall, w = core paleness, negative means more saturated toward the core), `oFleshWall` (vesicle wall colour), `oExtra` (wax coat weight, pebble amplitude in metres, navel opening in radians, hollow core fraction); `oRindStem.w` is the stem tint amount.
  - `Frame` tail (render): `uGround` (ground map centre xz, uv scale, receiver y), `uGround2` (x enabled, yzw flesh tint for light leaking through pieces), `uOccluderMfp` (rgb mean free path in metres, w leak strength), `uKeyShape` (key half-angle tangents, light-pool radius and strength). `uOccluderTint` is now the rind-derived bounce tint (rgb) and bounce strength (w); the renderer fills both tints from the `Orange` block (`oRind`, `oFlesh`, found by name).
- **Per-draw uniforms**: `uModel`, `uPrevModel` (for velocity), `uMaterialColor`.
- **Surface**: each material defines `Surface materialSurface(SurfaceInput si)` and returns a world-space `N`. `SurfaceInput` holds `rest`, `restNormal`, `world`, `normal`, `V`, `cap` (1 on cut faces), `restToWorld`, `pixel` (world size of a pixel, for `fwidth`-style filtering). The lighting (`shadeSurface`) never knows about anatomy.
- **Surface field meanings**: `sssProfile` is 0 none, 1 rind, 2 pith/core, 3 flesh, with `sssWidth` in 0..1. They are encoded into diffuse alpha by `encodeProfile`. `sssColor` tints the wrapped terminator light. `transmission` is lit through shadow-map thickness. `cavity` multiplies the AO. `emission` goes into the specular target. A clearcoat on a surface with `f0 <= 0.03` is treated as the same wet interface (juice film): its lobe replaces the base lobe by `clearcoat` instead of stacking; above that it is a separate wax/varnish layer with F0 0.04. Translucency uses per-profile mean free paths (`profileMfp`).
- **Main pass outputs** (MRT): `outDiffuse` = diffuse *irradiance* before albedo (alpha = SSS profile), `outSpecular` = specular radiance + emission, `outAlbedo` = `s.albedo`. `shadeSurface` returns irradiance in `diffuse`; the SSS pass blurs irradiance and `combine` multiplies by albedo. Extra diffuse radiance terms (wrap, transmission) are divided by albedo inside `shadeSurface`.
- **Ground receivers**: materials listed in `GROUND_RECEIVERS` (`shaders/materials.js`) compile with `GROUND_RECEIVER` and take ambient occlusion, bent normal and key-light visibility (area-light ray march over a top-down height map of the pieces, with light leaking through them) from `shadows.js` instead of PCSS. Pieces use PCSS against the key shadow map plus a back-depth map for transmitted light.
- **Scene fields** (render): `occluder { bounce, leak, mfp, bounceWhite }`, `grade { tonemap, white, contrast, saturation, balance, pathToWhite, toe, vignette, grain, bloom, bloomThreshold }`, `pool [radius, strength]`, `dof` (f-stop for always-on depth of field on high+), `groundReach`. `frame.focusPoint` (world point) and `frame.fStop` are optional; without a focus point the renderer auto-focuses on the piece nearest the screen centre.
- **Materials**: `MATERIALS` in `shaders/materials.js` maps a name to GLSL. Drawables carry `material`, which selects the compiled program. Adding a material means one GLSL entry plus a scene backdrop or a drawable that uses it.
- **Render pass**: insert `{ name, enabled(ctx), run(ctx) }` into `renderer.passes` at the right position. Read `ctx.targets` (depth, normal, velocity, diffuse, specular, albedo, hdr, hdrCopy) and the current `ctx.color`, and set `ctx.color` to your output. Allocate size-dependent targets in a `resize` (see `post.js`). Never sample a texture that is attached to the bound FBO.
- **Pieces**: `{ id, geometry: { data, count, planes, params, support }, com, volume, radius, caps[], gpu, proxy, planes, planeCount, position, rotation, model, prevModel, body, squash }`. Vertex layout is `STRIDE = 7`: position, normal, cap flag (non-indexed triangles). Caps hold `id`, `normal`, `d`, `area`, `centroid`, `tris`. The cap flag in the vertex data is the cap id (> 0.5); `geometry.planes[id]` is the cap's outward plane `[n, d]` (inside ⇔ `n·p ≤ d`), `geometry.params` the orange params and `geometry.support` the orange's support planes (`proxy.js supportPlanes`, set once per orange in `world.newOrange`, carried through `slicePiece`). `geometry` is physics / picking / juice only and is never drawn.
- **Drawing pieces (ray-marched field)**: a piece's `gpu` mesh is its convex proxy (`pieceProxy(support, planes)`: support polytope ∩ cut half-spaces lifted by `RELIEF_MARGIN`, position-only, outward CCW), drawn front faces only (back faces with the ray starting at the eye when the camera is inside the proxy). `piece.planes` is a `Float32Array(4 · MAX_PLANES)` (`MAX_PLANES = 12`) of the active rest planes. Drawables carry `march: true`; the renderer assigns `pieceId` (1..254) per frame. Per draw (`bindPiece`): `uModel`, `uPrevModel`, `uInvModel`, `uEye` (rest eye, w = 1; w = 2 inside the proxy; w = 0 for a rest ray direction in the shadow pass), `uPlanes`, `uPlaneCount`, `uBound` (rest bounding sphere), `uPieceId`, plus the orange sampler map.
  - Body SDF: `max(envelope(p), max_i(n_i·p − d_i − lift))`, `envelope = (|p| − shapeAt(p̂).x − envelopeRelief(p)) · 0.88` (0.3 within 7 mm of the stem axis); `lift = H_MAX` in the prepass, 0 in the shadow pass. The interior field is never evaluated during the march.
  - Cut surface: the height field `n·p − d = cutHeight(p, plane)` (`H_MIN = −0.6 mm` … `H_MAX = +0.8 mm`, evaluated on the plane-projected point, so it is single-valued) solved by 2–4 parallax iterations inside a face, or a stepped secant search near cut edges, ridges and grazing rays, with an analytic plane fallback. Hit classification: the largest CSG term wins (plane → cut face → `cutSurface`, envelope → rind → `rindSurface`).
  - Passes: **prepass** marches, writes `gl_FragDepth`, view normal (alpha = `pieceId / 255`, other geometry writes 1) and per-pixel velocity from the hit; **main** draws the proxies into a colour-only FBO (`fbos.pieces`, no depth test) and only for pixels whose prepass id matches, reconstructs the hit from the depth target and shades it (no second march); **shadow** marches the coarse body (`shadows.setPieces`). Shadow back depth and the ground height map rasterise the proxies.
  - Quality tiers (`uFlags.x`): coarse steps 24/32/40/48, relief iterations 2/3/3/4 (search steps 4/5/6/8), deep-layer samples 0/3/4/6 (low/medium/high/ultra).
- **Interior field** (`field-glsl.js`, rest space, +Y axis): `Anat anatomy(p)` gives shape radii, depth below the rind (`depthO`) and below the pulp boundary (`depthP`), segment index from `oSegB` bounds plus wavy, curved septa (`septumRel`), `u ∈ [−1, 1]` across the segment, septum distance `dS`, torn core radius and `inSeg` (segment interior distance with rounded dorsal and core corners: septa, white corner fills and the core star come from it). `Sac sacsAt(A)`: juice sacs as tapered spindles in lanes — columns in segment-angle space (fixed count per segment, chevron convergence), rows along `y + 0.22·S` (stylar tilt), 1–3 spindles per lane along `S` (horizontal depth from the dorsal wall); the 2×2 nearest lanes are evaluated and the most interior sac wins (`sdf`, `e`, `id`, `t`, `second`). `cutHeight(p, plane)` (domes, ruptured/dragged sacs per cut, juice-filled gaps with a meniscus, recessed septa, proud fibrous core tuft, segment bulge) and `Surface cutSurface(si, plane, Nrest)` (flavedo with gland cavities from `glandAt`, jagged flavedo/albedo teeth, fibrous albedo, wet pith rim, stem cross-section, core, sac walls as open in-plane bands, wrinkle micro-normals, refracted deep layer with Beer–Lambert weights, juice film). No cell/Voronoi functions remain on the fruit.
- **Physics**: never give pieces convex-hull contacts; polyhedron contacts in the vendored Rapier creep and tunnel. Contacts are balls (`contactBalls`), statics are cuboids. Collision groups: statics collide with all balls, a coverage subset of each piece's balls (`GROUP_TOUCH`) also collides between pieces. Never call `body.sleep()` by hand (woken bodies then fall through statics): resting pieces are `held` (velocities zeroed each step) and Rapier sleeps them itself. Piece fields owned by physics: `body`, `held`, `contact` (`'ground' | 'piece' | null`), `rolling`, `restTime`, `freshUntil`.
- **Juice**: `cutBurst(piece, cap, params, amount)`, `fresh(piece, cap, seconds)` (drips from the lowest edge), `tint` (floor stain tint). The wetness map is RG16F: R = water (dries in ~50 s), G = deposit (stays). The cove material reads it in `applyWetness` and takes `uniform vec3 uJuiceTint`, set once by `main.js` on the cove program.
- **Materials**: `steel` (knife): `cap` attribute 1 = wooden handle, 0 = steel; shading uses rest (local knife) coordinates.
- **Test API additions**: `poses()`, `project(point)`, `contacts()` (`floor` = lowest piece point above the floor, `overlap` = deepest hull point inside another piece), `wetness()` (stain area, m²); `info()` adds `knife, splats, drips, muted`. Keys: K/H tools, 1–4 presets, N new orange, R reset, A sound, P screenshot.
- **Test mode** (`?test`): `rAF` does not advance anything; `apelsin.step(n)` runs n fixed 1/60 s frames; the camera snaps. `?debug` adds `apelsin.internals`.
